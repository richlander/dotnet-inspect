; Every browser interaction that inspects an assembly runs inside a workspace, through a public
; product query that owns the session, the metadata source, and the analysis index. This file is
; that rule, enforced by the compiler's semantic model through BannedApiAnalyzers rather than by a
; scan of the source text — a scan has to model C# to know what a name binds to, and every
; spelling it does not model is a hole.
;
; Product-owned package realization selects assets, decodes identities, mints descriptors, and
; constructs roles. The engine cannot reach descriptor factories, PEReader, MetadataReader, an
; inspection session, a metadata source, a body index, or a retained image directly.
;
; BrowserEngineLayeringTests in engine.Tests pins this file into the engine project and
; checks that every identifier below still resolves, so a rename cannot leave a silently vacuous
; entry behind.
