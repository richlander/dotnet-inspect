; Every browser interaction that inspects an assembly runs inside a workspace, through a public
; product query that owns the session, the metadata source, and the analysis index. This file is
; that rule, enforced by the compiler's semantic model through BannedApiAnalyzers rather than by a
; scan of the source text — a scan has to model C# to know what a name binds to, and every
; spelling it does not model is a hole.
;
; Acquisition is deliberately not banned. Minting a participant requires decoding the entry's real
; metadata identity, because the workspace validates every image it acquires against its
; descriptor, so PEReader and MetadataReader stay reachable for that one purpose. What is banned
; is inspection: opening a session, a metadata source, or a body index, and reaching a group's
; image bytes or retained descriptor directly.
;
; BrowserEngineLayeringTests in src/dotnet-inspect.Tests pins this file into the engine project and
; checks that every identifier below still resolves, so a rename cannot leave a silently vacuous
; entry behind.
