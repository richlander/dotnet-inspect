; Product inspection parses assembly bytes with System.Reflection.Metadata and
; System.Reflection.PortableExecutable. It must never load inspected assemblies
; into the runtime, emit executable code, or activate target types.
;
; The compiler's semantic model enforces this list for projects marked with
; IsInspectionProductProject. AssemblyLoadingPolicyTests verifies that shipped
; product closures receive it and builds a negative canary that must fail with
; RS0030.
